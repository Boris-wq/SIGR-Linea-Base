
# Sistema Integral de Gestión de Restaurante (SIGR)

## Descripción del proyecto

El Sistema Integral de Gestión de Restaurante (SIGR) es una propuesta de software web pensada para facilitar la administración y el funcionamiento diario de un restaurante.

La idea es reunir en un solo lugar las tareas relacionadas con los clientes, el menú, los pedidos, las reservas y el control de las ventas.

## Objetivo del proyecto

Organizar la documentación funcional del sistema y establecer una línea base que permita identificar sus componentes y mantener un control de los cambios realizados durante el desarrollo del proyecto.

## Módulos principales

El sistema estará organizado en cinco módulos:

1. **Autenticación de usuarios:** permite el acceso según el perfil de cada usuario.
2. **Menú digital:** facilita la consulta y administración de platos y categorías.
3. **Gestión de pedidos:** permite registrar los pedidos y consultar su estado.
4. **Reservas:** organiza las solicitudes de mesas por fecha y hora.
5. **Caja y reportes:** permite registrar pagos y consultar las ventas del restaurante.

## Organización del repositorio

La documentación del proyecto se organizará de la siguiente manera:

- `README.md`: presentación general del proyecto.
- `CHANGELOG.md`: registro de los cambios realizados.
- `LICENSE.txt`: información sobre la licencia.
- `docs/`: carpeta con la documentación funcional y técnica.

## Control de versiones

Para organizar el proyecto se utilizará Git y GitHub. Estas herramientas permitirán conservar el historial de modificaciones y mantener identificada cada versión de la documentación.

## Estado actual

El proyecto se encuentra en la etapa de documentación y definición de su línea base. Este repositorio servirá como espacio de trabajo para organizar y controlar los documentos del SIGR.
