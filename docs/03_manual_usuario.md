
# Manual de usuario del Sistema Integral de Gestión de Restaurante (SIGR)

## 1. Introducción

Este manual explica cómo utilizar las principales funciones del Sistema Integral de Gestión de Restaurante (SIGR).

Está dirigido a los clientes, meseros y administradores. Cada perfil tendrá acceso a diferentes opciones según las actividades que realice dentro del restaurante.

## 2. Ingreso al sistema

Para comenzar a utilizar la plataforma, el usuario deberá ingresar a la página web del restaurante.

### Procedimiento

1. Abrir la página web del restaurante.
2. Seleccionar la opción de iniciar sesión.
3. Escribir el correo electrónico y la contraseña.
4. Seleccionar el botón de ingreso.
5. Esperar la validación de los datos.

Una vez realizado este proceso, el sistema mostrará las opciones correspondientes al perfil del usuario.

## 3. Uso del sistema como cliente

El cliente podrá consultar los productos y utilizar las opciones disponibles para realizar pedidos o solicitar una reserva.

### 3.1 Consultar el menú digital

1. Ingresar a la página web.
2. Seleccionar la opción Menú.
3. Consultar las categorías disponibles.
4. Seleccionar un plato para conocer su descripción y precio.
5. Verificar que el producto se encuentre disponible.

### 3.2 Realizar un pedido

1. Seleccionar los platos que desea solicitar.
2. Indicar la cantidad de cada producto.
3. Revisar el resumen del pedido.
4. Verificar el valor total.
5. Confirmar la solicitud.

Después de confirmar, el pedido quedará registrado para que el personal del restaurante pueda gestionarlo.

### 3.3 Solicitar una reserva

1. Ingresar a la opción Reservas.
2. Seleccionar la fecha deseada.
3. Indicar la hora y el número de personas.
4. Completar los datos de contacto.
5. Enviar la solicitud.

El restaurante podrá revisar la disponibilidad y confirmar o rechazar la solicitud.

## 4. Uso del sistema como mesero

El mesero utilizará la plataforma para apoyar la atención de los clientes y mantener organizados los pedidos.

### 4.1 Consultar el menú

1. Iniciar sesión con su cuenta.
2. Abrir el módulo de menú digital.
3. Consultar los platos y sus precios.
4. Verificar la disponibilidad de los productos.

### 4.2 Registrar un pedido

1. Ingresar al módulo de pedidos.
2. Seleccionar la mesa o el tipo de servicio.
3. Agregar los productos solicitados.
4. Indicar las cantidades.
5. Revisar el resumen.
6. Confirmar el registro del pedido.

### 4.3 Consultar el estado de un pedido

1. Abrir el módulo de pedidos.
2. Buscar el pedido correspondiente.
3. Consultar su estado actual.
4. Informar al cliente sobre el avance cuando sea necesario.

Los estados permitirán identificar si el pedido está registrado, en preparación, listo o entregado.

## 5. Uso del sistema como administrador

El administrador tendrá acceso a las opciones de supervisión y configuración del restaurante.

### 5.1 Administrar usuarios

1. Iniciar sesión como administrador.
2. Ingresar al módulo de autenticación o administración de usuarios.
3. Consultar las cuentas registradas.
4. Crear o actualizar usuarios según las necesidades.
5. Asignar los perfiles y permisos correspondientes.

### 5.2 Administrar el menú

1. Ingresar al módulo de menú digital.
2. Seleccionar la opción de administración.
3. Agregar un nuevo plato o seleccionar uno existente.
4. Registrar o modificar su nombre, descripción y precio.
5. Asignar una categoría.
6. Actualizar su disponibilidad.
7. Guardar los cambios.

### 5.3 Supervisar pedidos y reservas

1. Ingresar al módulo correspondiente.
2. Consultar los pedidos y las reservas registradas.
3. Revisar sus estados.
4. Actualizar la información cuando corresponda.
5. Verificar que las solicitudes estén siendo atendidas.

### 5.4 Consultar caja y reportes

1. Ingresar al módulo de caja.
2. Seleccionar el periodo que desea consultar.
3. Revisar los pagos registrados.
4. Consultar el total de las ventas.
5. Verificar la información antes de realizar el cierre diario.
6. Consultar el reporte generado.

## 6. Recomendaciones para los usuarios

- Mantener actualizados los datos de acceso.
- No compartir las contraseñas con otras personas.
- Verificar los productos y las cantidades antes de confirmar un pedido.
- Revisar la fecha y la hora antes de solicitar una reserva.
- Informar al administrador cuando se presente alguna dificultad.
- Cerrar la sesión al terminar de utilizar la plataforma.

## 7. Consideraciones del manual

Este documento describe el funcionamiento previsto del SIGR. Los procedimientos corresponden a una propuesta de uso y no a una aplicación que ya se encuentre desarrollada.

Durante una futura implementación, los pasos podrán ajustarse de acuerdo con el diseño definitivo de las pantallas y las funciones disponibles.

## 8. Relación con la línea base

El manual forma parte de la documentación inicial del proyecto. Cualquier modificación en los procedimientos o en las funciones descritas deberá revisarse y registrarse en el historial de cambios del repositorio.
